# Node.js 방 코드 서버 — 남은 점검 항목

서버 코드는 저장소 루트 `Server/`(API 설명: `Server/README.md`). 2026-10-10 리뷰에서 N-1~N-5(호스트 주소, 인원 집계, 삭제, 만료/하트비트, 토큰 인증·입력 검증)는 수정 완료 — 기록은 `Docs/review/review-progress-2.md`의 "Node 서버 리뷰", 테스트는 `review-tests-2.md`의 N-0~N-7.
아래는 **아직 처리하지 않은 것**만 남긴다. 서버를 고칠 때는 짝이 되는 Unity 쪽(`RoomHost`, `RoomJoin`, `TitleUI.StartHost`, `RoomManager`)도 함께 고친다.

## 서버
- [ ] 평문 HTTP — 외부 공개 시 HTTPS 결정 필요(같은 망에서 토큰 엿보기 가능)
- [ ] pm2는 설정만 넣음(`Server/ecosystem.config.js`) — 서버 PC에 `npm install -g pm2` 후 `npm run pm2`로 실행할지는 사용자가 정함
- [ ] 요청 횟수 제한은 서버 메모리에만 있음(재시작하면 초기화, 여러 서버로 늘리면 공유 안 됨) — 외부 공개 전에 충분한지 검토
- [ ] 서버를 껐다 켜야 하는 테스트(서버 다운 팝업, 재시작 후 방 유지) — 사용자 승인 대기

## 접속 구조 (결정 필요)
- [ ] 호스트의 UDP 7777이 외부에 열려 있어야 접속 가능 → 릴레이 또는 전용 서버 도입 여부
- [ ] 호스트가 같은 공유기 안 다른 기기면 사설 IP가 저장되어 외부 입장 불가
- [ ] 호스트 이탈 시 방 소멸(호스트 이전 없음), 튕긴 플레이어 재접속 불가 → 유지 여부
- [ ] 원본 저장소 업로드 — 주소·브랜치·권한을 사용자에게 받아야 함
